## Selected work

### [The Holographic Atlas — AdS/CFT](https://github.com/OliviaRieva/ads-cft-atlas)

[Open the learning website](https://holographic-atlas.oliviarieva.chatgpt.site) · [CFT and AdS reading paths](https://holographic-atlas.oliviarieva.chatgpt.site/notes) · [Interactive D3-brane lab](https://holographic-atlas.oliviarieva.chatgpt.site/correspondence)

A bottom-up gauge/gravity duality study companion with native equations, independent CFT and AdS reading columns, an interactive correspondence dictionary, movable branes and redshift observers, and persistent practice quizzes.

**My role:** learning goals, personal study notes, research questions, interaction design, and iterative feedback. The implementation and explanatory content were developed with Codex. The repository includes numerical and rendering tests, visible model limitations, and attribution to the original course authors.

### [RIEVA — Exploration Systems Laboratory](https://github.com/OliviaRieva/rieva-exploration-lab)

[Launch the live laboratory](https://rieva-exploration-lab.oliviarieva.chatgpt.site)

An interactive aerospace research portfolio with four connected laboratories:

- low-thrust orbital transfer and engine-interruption simulation;
- calculated Kerr black-hole diagnostics;
- Blender-authored missionwear configuration and materials research;
- an original Blender aircraft with educational aerodynamics and an evidence-based astrobiology desk.

**My role:** concept, research direction, product design, scenario definition, testing, and iterative evaluation. The implementation was developed iteratively with Codex. The repository includes automated physics, configuration, asset, and rendered-page checks; model boundaries are stated alongside the results.

### [Molecular Visualization Study](https://github.com/OliviaRieva/molecular-visualization-study)

A non-code case study comparing fast terminal-driven molecular previews with higher-fidelity Blender renders across planar, non-planar, elongated, and periodic structures.

**My role:** testing, visual quality assurance, terminal-versus-Blender comparison, stress-case selection, and evaluation of framing, occlusion, and readability. Mark Jones / Molecular Quantum Solutions implemented the private software used in the original collaboration; their code is not redistributed or claimed as mine.

## How I work

- Make assumptions and units visible.
- Validate numerical behavior against invariants, analytical results, and convergence checks.
- Keep operational heritage, active research, and speculative concepts clearly separated.
- Treat polished visualization as communication—not as evidence that a model is physically complete.
- Credit collaborators and tool-assisted implementation directly.
